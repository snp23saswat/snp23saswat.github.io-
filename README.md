# snp23saswat.github.io

Personal portfolio site for **Saswat Nemalipuri**, published via GitHub Pages.

**Live site:** https://snp23saswat.github.io/snp23saswat.github.io-/
*(or your custom Pages URL, if configured under repo Settings → Pages)*

## About

A single-page, minimal portfolio site — clean typography (Fraunces + Inter), warm color palette, and a simple layout for an intro, role, and contact details.

## Tech Stack

- Plain HTML + CSS (no build step / framework)
- Google Fonts (Fraunces, Inter)

## Running Locally

No build tools needed — just open the file directly:

```bash
git clone https://github.com/snp23saswat/snp23saswat.github.io-.git
cd snp23saswat.github.io-
open index.html   # or double-click it, or use a local server e.g. `npx serve`
```

## Deployment

This repo is set up for GitHub Pages. Make sure **Settings → Pages → Source** is pointed at the correct branch (`main`) and folder (`/root`) so it publishes automatically on push.

## Notes

> Since this is your personal site, consider: renaming the repo to drop the trailing `-` (e.g. `snp23saswat.github.io`) so it can serve directly at `https://snp23saswat.github.io` — GitHub Pages user sites only auto-publish at the root domain when the repo is named *exactly* `<username>.github.io`. Also worth adding a project/work section and a resume link if you want it to double as a portfolio for recruiters.
